This repo contains the steps to package PyNitrokey (<https://github.com/Nitrokey/pynitrokey/>) for Fedora

Unpackaged dependencies for `pynitrokey` (ignoring version constraints):
* `nethsm` (<https://github.com/Nitrokey/nethsm-sdk-py/>)
* `nitrokey` (<https://github.com/Nitrokey/nitrokey-sdk-py>)
* `nkdfu` (<https://github.com/Nitrokey/nkdfu/>)
    * `fire` (<https://github.com/google/python-fire>) (only on rawhide)
* `tlv8` (<https://github.com/jlusiardi/tlv8_python>)
